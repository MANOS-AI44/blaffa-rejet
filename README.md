# BLAFFA REJET

Robot multi-utilisateurs de rejet automatique des demandes de dépôt anciennes sur **managment.io**, déployable en un clic sur **Railway**.

## ✨ Fonctionnalités

- **Multi-utilisateurs** avec compte administrateur et utilisateurs distincts
- **Cookies indépendants** : chaque utilisateur injecte ses propres cookies managment.io
- **Seuils configurables** : 10 min, 13 min, 30 min, 2 h, 6 h
- **Robot continu 24/7** : tourne sur le serveur Railway, pas de dépendance à votre navigateur
- **Tableau de bord détaillé** : N° demande, identifiant utilisateur, numéro, montant, banque, processing time
- **Vue admin globale** : statistiques agrégées, gestion des comptes, historique de tous les rejets
- **Journal du robot** : visualisation des actions du robot pour chaque utilisateur
